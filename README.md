# Zone Zero Media

Static GitHub Pages version.

## Upload to GitHub Pages

1. Create a repository
2. Upload all files
3. Go to:
   Settings -> Pages
4. Select:
   Deploy from branch -> main -> root
5. Save

Done.

## Features

- 5v5 image generator
- LocalStorage save/load
- TXT export/import
- Username autocomplete
- Style autocomplete
- Mobile sidebar
- Canvas image export
